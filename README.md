# Путешественник по России

Небольшая панель для планирования путешествий по России. Проект сделан на обычных HTML, CSS и JavaScript (ES-модули), без Node.js, npm, серверной части и сторонних библиотек.

## Как открыть проект

1. Распакуйте архив.
2. Откройте папку `russia-traveler-dashboard` в Visual Studio Code.
3. Откройте `index.html` через расширение предпросмотра, например Live Server, либо опубликуйте проект на GitHub Pages.
4. Для виджетов, которые получают данные из интернета, необходимо подключение к сети.

> Если предпросмотр открывает страницу, но браузер блокирует ES-модули при открытии файла напрямую, используйте Live Server в VS Code. Для публикации на GitHub Pages никаких дополнительных сервисов не требуется.

## Что умеет приложение

- Добавлять и удалять виджеты: погода, информация о месте, список вещей, маршрут, бюджет и совет путешественнику.
- Сохранять открытые виджеты, их порядок, введённые значения, список вещей, отмеченные пункты и расходы.
- Запоминать имя пользователя и показывать персональное приветствие.
- Сохранять избранные города. Нажатие на город подставляет его в поиск и обновляет виджеты погоды и места.
- Получать прогноз через Open-Meteo, искать сведения о местах через Wikipedia.

## Где хранятся сохранения

Данные записываются в `localStorage` браузера. Они сохраняются после закрытия вкладки и повторного открытия сайта **в том же браузере и на том же устройстве**. Данные не передаются на сервер и не синхронизируются между разными устройствами или браузерами. Если очистить данные сайта в браузере, сохранения будут удалены.

## Публикация на GitHub Pages

Загрузите содержимое этой папки в репозиторий GitHub. Затем откройте **Settings → Pages**, в разделе сборки выберите публикацию из ветки `main` и папки `/(root)`, сохраните настройки и дождитесь появления ссылки на сайт.


## Как открыть проект без Live Server

1. Распакуйте архив целиком.
2. Откройте папку проекта в Visual Studio Code.
3. Можно открыть `index.html` двойным щелчком — приложение загружается через обычный `app.bundle.js`, без ES-модулей и без сборщика.
4. Для публикации на GitHub Pages загрузите все файлы и папки проекта в репозиторий, затем в настройках Pages выберите публикацию из нужной ветки и корневой папки (`/`).

`app.bundle.js` — готовый объединённый скрипт для запуска без сервера. Отдельные файлы в `js/` оставлены в проекте для удобства чтения и дальнейшей разработки. На GitHub Pages также используется `app.bundle.js`.

**Важно:** при открытии через `file://` браузер может ограничивать запросы к внешним API. В таком случае сама страница и локальные сохранения работают, а погода/поиск мест могут полноценно загружать данные после публикации на GitHub Pages, где сайт открывается по HTTPS.
