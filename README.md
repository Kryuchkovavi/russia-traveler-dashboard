# Путешественник по России

Интерактивная Dashboard-панель для планирования путешествий по России.

## Возможности

В приложении доступны виджеты:

* 🌤 Погода
* 🧳 Список вещей
* 📍 Маршрут
* 💰 Бюджет
* ✦ Совет путешественнику
* 🏙️ Место

Виджеты можно добавлять и удалять независимо друг от друга.

## Структура

```text
index.html — основная HTML-страница
main.js — запуск приложения
js/ — классы и логика виджетов
styles/ — стили проекта
```

Основой всех виджетов является класс `UIComponent`. Управление виджетами выполняет класс `Dashboard`.

## API

В проекте используются:

* **Open-Meteo** — поиск городов и получение погодных данных.
* **Wikipedia / Wikimedia** — получение информации о местах.

API не требуют хранения секретного ключа в проекте.

## Технологии

* HTML5
* CSS3
* JavaScript ES6+
* ES6 Modules
* ООП
* Fetch API
* AbortController
* CSS Grid
* CSS Flexbox


## Ограничения

Расстояние и время в виджете маршрута являются приблизительными.

Работа виджетов «Погода» и «Место» зависит от доступности внешних API.

## Использование ИИ

ИИ использовался как вспомогательный инструмент при разработке проекта:

* для поиска и исправления ошибок;
* помощи с отдельными фрагментами кода;
* проверки структуры проекта;
* объяснения работы JavaScript и API;
* проверки соответствия требованиям задания.
